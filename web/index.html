Railway Ticket Reservation System

Search trains, check seat availability, book tickets, cancel reservations and manage train records, all from one menu-driven application.

What would you like to do?

  • Passengers Search Trains Find trains by route or train number and check seat availability.
  • Passengers Book a Ticket Enter passenger details and receive a PNR, seat number and fare.
  • Passengers Cancel a Ticket Cancel with your PNR and see the refund amount.
  • Staff Admin Login Sign in to add, modify or delete trains and view bookings.

Search Trains

Look up trains and see how many seats are left before you book.

  • Option 2 searches by source and destination. Matching ignores capital letters and extra spaces.
  • Option 3 searches by train number.
  • Option 4 shows full train details with total, booked and available seats.

Book a Ticket

Option 5 asks for these details, one prompt at a time:

  1. Train number
  2. Passenger name
  3. Passenger age
  4. Gender (M, F or O)
  5. Mobile number

You receive a confirmation with a 10-digit PNR, your seat number and the fare. Keep the PNR: option 6 shows the booking again at any time.

Back to top

Cancel a Ticket

Option 7 cancels a booking using its PNR. The seat is released for other passengers, and the original fare, the 10% cancellation charge and your refund are shown. A booking can only be cancelled once.

Back to top

Admin Login

Option 8 opens administrator login. Three failed attempts return you to the main menu. After signing in, an administrator can:

  • Add and modify trains
  • View all trains and all bookings
  • Delete trains that have no confirmed bookings

Run the application

The system is a C++17 console program. From the project folder:

g++ -std=c++17 -Iinclude src/*.cpp -o railway
./railway
